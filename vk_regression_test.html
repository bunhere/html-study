모드: visual(기본) content(Gemini) overlays(ChatGPT) meta없음

화면 맨 아래 빨강·노랑 줄무늬 바는 웹 영역 바닥에 붙어 있습니다. 키보드를 띄웠을 때 이 바가 키보드 바로 위에 붙어 있어야 하고(resizes-content), 바와 키보드 사이에 빈 띠가 있으면 안 됩니다. 기준값(키보드 없을 때)은 입력창에 포커스가 없을 때 자동으로 기록됩니다.

1. 일반 입력 (C-1, A-1)

탭 → HUD 판정 확인. visual: inner 변화 0, vv 만 줄어야 함. content: inner 가 키보드만큼 줄고 바닥 바가 키보드 위. overlays: inner 변화 0, vk.rect 높이 > 0.

2. 다이얼로그 (B-2, B-3)

버튼 → 다이얼로그 입력란에 키보드를 띄워 입력 → 닫기. 아래 결과에 다이얼로그 동안 웹 resize 0회여야 합니다. 닫은 뒤 바로 1번 입력창을 탭해 판정이 정상인지도 확인(B-3).

3. 찾기 툴바 (B-1)

3닷 → 페이지 내 찾기 → 찾기테스트 입력. 찾기 툴바가 키보드 바로 위에 붙어야 하고, 키보드 높이만큼 떠 있으면 실패. 키보드 내렸다 올리기, 찾기 닫고 다시 열기도 반복.

4. 알림창 (B-4)

1번 입력창으로 키보드를 띄운 상태에서 알림창을 내렸다 올리기. 아래 카운터가 늘지 않아야 합니다.

5. 분할 화면 / 크기 변화 (D-2)

overlays 모드에서 키보드를 띄운 채 분할선 드래그 → 키보드를 닫았을 때 inner 가 화면 크기와 맞는지(높이가 예전 값에 고정되지 않는지).

6. 바닥 입력 (스크롤 진입)

페이지 맨 아래 입력창을 탭 → HUD 의 포커스 입력창 보임이 yes 여야 합니다.
